## 数据集概述

本数据集专注于**古建筑整体结构及组件的视觉检测与识别**，服务于古建筑保护、文物数字化建档及建筑遗产研究。数据涵盖五类古建筑相关目标，适配古建巡检、古建筑普查及自动化目标识别等应用。

## 数据三要素解析

**类别与目标覆盖**
*   数据集定义 **5** 类古建筑相关目标，覆盖 **建筑整体**（单体古建筑、门楼、牌坊、塔）与 **关键构件**（斗拱）。
*   类别设置兼顾了宏观建筑识别与微观构件检测，服务于古建筑的综合评估。
*   图像涵盖不同拍摄角度、光照条件下的古建筑外观。

**数据规模与版本**
*   图像总量约 **1971** 张，规模适中，能支撑多类别目标检测模型的训练。
*   数据集有 **2** 个版本，可能包含不同标注完善度或数据增强的迭代版本。
*   图像包含实景照片、建筑模型及邮票等多种形态的古建筑图像，场景多样性较强。

**格式与结构**
*   采用通用 **YOLO 格式**（txt），每张图像对应一个同名标签文件，包含类别 ID 与归一化边界框坐标，可直接接入 YOLOv5、YOLOv8 等主流检测框架。
*   图像与标签一一对应，数据结构规范，便于进行训练/验证集划分与预处理集成。

## 知识普及：古建筑目标检测的技术要点

*   **尺度差异极大**：从宏大的塔类建筑到局部的斗拱构件，目标尺度跨度大，需采用多尺度特征融合策略。
*   **形态与结构复杂**：古建筑的结构繁复（如飞檐、斗拱），轮廓不规则，对模型的边界提取能力要求较高。
*   **背景干扰**：古建筑多位于自然或城市环境中，背景包含树木、天空、现代建筑等，可能与目标混淆。
*   **数据多样性**：包含实景与邮票等非实景图像，有助于提升模型对不同图像风格和成像质量的泛化能力。
*   **应用闭环**：检测结果可导入古建筑GIS或BIM系统，用于建筑普查、状态评估与修缮规划，服务于建筑遗产的数字化保护。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例（类别名称需替换为您实际使用的中文名称）：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 5
names: ['单体古建筑', '斗拱构件', '古建筑门楼', '古建筑牌坊', '塔类建筑']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
